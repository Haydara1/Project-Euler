# Project Euler Solutions

My solutions to [Project Euler](https://projecteuler.net/) problems, written in **C#**.

The goal of this repository is to improve my problem-solving skills, strengthen my mathematical intuition, and explore the relationship between mathematics and programming.

## Progress

![Problems Solved](https://img.shields.io/badge/Solved-33%2F100-blue)
![Language](https://img.shields.io/badge/Language-C%23-purple)

## Approach

I try to understand the mathematical ideas behind each problem before implementing a solution.

Some of the concepts explored include:

- Number theory
- Prime numbers and factorization
- Modular arithmetic
- Combinatorics
- Dynamic programming
- Algorithms and optimization

## Technologies

- **Language:** C#
- **Platform:** .NET & rider.
- **Version Control:** Git

### Side note:
Project Euler has over a thousand problems to solve, but only allows solutions to the problems 1 to 100 to be published.
